# 148 Environment

This folder represents the development + model lab environment.

## Roles
- Dev app: auto-reload enabled for experimentation
- Approved model service: stable internal inference endpoint for 152
- Registry: stores approved model versions and production pointer

## Start dev mode
```bat
148\scripts\start_dev_148.bat
```

## Start approved production model service
```bat
148\scripts\start_prod_model_148.bat
```
